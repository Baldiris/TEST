# Regional SVG Maps

The active 18 maps are generated by `node scripts/generate-jr-maps.js`.
Edit `layout-data.json` for station coordinates, optional corridor guides and lane offsets.
Do not edit generated SVGs directly: CI checks reproducibility.

Connectivity comes only from `../network-data.js`. A guide can include intermediate visual waypoints without adding game stops.
Each interactive node has one exact `data-station` and each generated track has `data-edge` containing `[from,to,service]`.
These keys select geometry for highlighting; they never create game connections.

`data-reference-station` marks non-game context. `data-label` lets current/goal/reachable labels remain visible in fit mode.
Every region includes all manifest stations, boundary stations, and region hubs.
`layout-report.json` records layout dimensions and conservative label-box collision checks; browser visual review is still required.
