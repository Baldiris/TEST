# きまぐれJR旅 — JR東日本 関東近郊 V0.3

メトロ版とは独立したJR版アプリです。

## 公開先

GitHub Pages: `/jr-east/`

## V0.3の方針

V0.3では、関東全域化に向けてゲームデータと地図描画データを分離しています。

- `network-data.js`: 路線・地域・関東Overview
- `app.js`: ゲームロジック
- `tokyo-core-map.svg`: 東京コア地域図
- 全299駅ネットワーク: 未完成地域のフォールバック

- 1駅間 = 1マス
- サイコロ1〜6
- 出目に応じた到達候補から駅を選択
- ゴールが出目以内ならゴールを選択可能
- 到着駅ごとにクエスト2件
