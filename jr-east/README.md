## ゲームルール

- 出発駅は収録駅からランダム
- ゴール駅は出発駅から最短5〜15駅を優先して抽選
- サイコロは1〜6
- 出目と最短距離が一致する駅を移動候補にする
- ゴールが出目以内ならゴール選択可
- 到着駅ごとにクエスト2件
- LocalStorageで進行保存
- メトロ版とは保存キーを分離

## データ設計

各路線は `LINES` 内の `paths` で定義しています。
今後、房総方面・成田線・青梅線・五日市線・八高線などを同じ形式で追加できます。
