# きまぐれ旅JR / 参照デザインプレビュー

`design-reference.html` は、添付された「KANTO RAIL TRIP」風の画面構成を既存V0.3から分離して確認するためのプレビューです。

- トップ: 淡い空色の背景、濃緑CTA、スマートフォン風のサイコロ表示、駅めぐりの特徴カード
- 遊び方: サイコロ → 駅確認 → クエスト → 記録の4ステップ
- ゲーム: 実際の `network-data.js`、539駅、34サービス、横浜・川崎SVGを使った操作プレビュー
- 既存本番: `index.html` と既存のV0.3セーブ形式は変更せず、デザイン検証用の独立ページとして追加

参照ページは、デザイン確認後に本番画面へ段階的に反映する前提です。画像をそのまま背景に埋め込まず、HTML/CSS/SVGでレイアウトとUIを再構成しています。
